# **Story App** 📖📍  

A modern Android app for sharing stories (images & descriptions) with location-based features. Built for **Dicoding's Android Intermediate Class**.  

## **Features** ✨  
✅ **Authentication** (Login/Register)  
✅ **Story Feed** (Pagination with **Paging 3**)  
✅ **Add Stories** (Image + Description)  
✅ **Interactive Maps** (Google Maps + Location Markers)  
✅ **Animations** (Smooth UI transitions)  
✅ **Unit Testing** (ViewModel & Data Validation)  

## **Tech Stack** 🛠️  
- **Kotlin**  
- **MVVM** Architecture  
- **Retrofit** (API)  
- **SharedPreferences** (Session)  
- **Google Maps SDK**  
- **Paging 3** (Infinite Loading)  

## **Installation** ⚙️  
1. Clone the repo  
   ```bash  
   git clone https://github.com/Yuda531/story-app.git  
   ```  
2. Open in **Android Studio**  
3. Build & Run!
